# Quick Revision Notes

## Q6 – Azure Advisor

### Correct Answer

**Azure Advisor**

### When to Use

Use Azure Advisor when you need personalized recommendations based on existing Azure resources.

### Five Recommendation Categories

- 💰 Cost
- 🔒 Security
- ❤️ Reliability
- ⚙️ Operational Excellence
- ⚡ Performance

### Exam Tip

> "Analyze existing resources and provide recommendations."

**Answer: Azure Advisor**

## Q7 – Azure Virtual Desktop

### Correct Answer

**Azure Virtual Desktop**

### Scenario

- Remote employees
- Windows 11 desktops
- Microsoft 365 applications
- Centralized management
- Low hardware requirements

### Azure VM vs Azure Virtual Desktop

| Azure VM | Azure Virtual Desktop |
|----------|------------------------|
| One VM per user | Multi-session desktops |
| Higher management | Centralized management |
| More expensive | Cost-effective |

### Exam Tip

> "Provide virtual Windows desktops."

**Answer: Azure Virtual Desktop**

---

## Q13 – Azure File Sync

### Correct Answer

**Azure File Sync**

### Scenario

- Multiple branch offices
- Local Windows file servers
- Centralized Azure Files
- Fast local access

### How It Works

- Stores files in Azure Files.
- Keeps frequently used files cached locally.
- Synchronizes changes automatically.

### Memory Trick

> **Cloud Storage + Local Cache = Azure File Sync**

## Q15 – Application Insights

### Correct Answer

**Application Insights**

### Use Cases

- Slow web applications
- Performance bottlenecks
- Dependency tracking
- User behavior analytics
- Automatic anomaly detection

### Relationship with Azure Monitor

| Service | Purpose |
|----------|----------|
| Azure Monitor | Platform monitoring |
| Application Insights | Application Performance Monitoring (APM) |

### Exam Tip

If the question mentions **slow web apps**, choose **Application Insights**.
