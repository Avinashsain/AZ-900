## Q5 – Availability Zones

**Answer:** Availability Zones are separate physical datacenters within the same Azure region.

**Exam Tip:** Datacenter failure = Availability Zones.

---

## Q11 – Azure Reserved Instances

**Answer:** Reserved Instances provide immediate VM cost savings.

**Exam Tip:** Predictable VM workload = Reserved Instances.

---

## Q12 – Purview Compliance Manager

**Answer:** Tracks compliance with GDPR, ISO 27001, and other standards.

**Exam Tip:** Compliance assessment = Purview Compliance Manager.

---

## Q13 – ARM Deployment Methods

**Correct Options:**
- Azure Portal
- Azure PowerShell
- Azure CLI
- REST API / SDK

**Exam Tip:** ARM works from Portal, CLI, PowerShell, and APIs.

---

## Q15 – Grant Azure Access

**Answer:** YES. Use Microsoft Entra ID + RBAC instead of sharing passwords.

**Exam Tip:** Never share passwords—assign a role.

---

## Q18 – VM Scale Set Limit

**Answer:** 1,000 VM instances (600 with custom images).

**Exam Tip:** VMSS = 1,000.

---

## Q20 – High Availability Principle

**Answer:** Design for resilience with **no single point of failure**.

**Exam Tip:** HA = Eliminate single points of failure.

---

## Q21 – Azure Policy

**Answer:** Azure Policy blocks non-compliant resources.

**Exam Tip:** RBAC grants permissions, but Policy still enforces restrictions.

---

## Q37 – Azure SLA

**Answer:** SLAs vary by service and cover uptime, performance, and connectivity.

**Exam Tip:** No single SLA for every Azure service.

---

## Q40 – HDInsight

**Answer:** Managed Apache Hadoop platform.

**Exam Tip:** Hadoop on Azure = HDInsight.
