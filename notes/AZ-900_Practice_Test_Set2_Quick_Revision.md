## Q3 – Azure VM Pricing
**Answer:** Reserved VM + Pay-as-you-go

**Exam Tip:** Baseline = Reserved VM | Peak = Pay-as-you-go

## Q7 – Azure PowerShell
**Answer:** Azure PowerShell

**Exam Tip:** Cmdlets = PowerShell

## Q13 – Azure ExpressRoute
**Answer:** Azure ExpressRoute

**Exam Tip:** Private + Dedicated + No Internet = ExpressRoute

## Q39 – Microsoft Entra ID B2C
**Answer:** Microsoft Entra ID B2C

**Exam Tip:** Customers = B2C

## Q42 – Private Endpoint
**Answer:** Private Endpoint

**Exam Tip:** Never Public Internet = Private Endpoint

## Q45 – Cool Tier
**Answer:** Cool Tier

**Exam Tip:** Rare Access + Immediate Retrieval = Cool Tier
