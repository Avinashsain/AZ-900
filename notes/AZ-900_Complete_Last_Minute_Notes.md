
# AZ-900 Complete Last-Minute Notes

## Cloud Concepts
- **OpEx:** Pay-as-you-go.
- **CapEx:** Upfront hardware purchase.
- **Scalability:** Increase capacity.
- **Elasticity:** Auto scale.
- **Reliability:** Reduce downtime.

## Cloud Models
- Public = Azure
- Private = Company datacenter
- Hybrid = Azure + On-prem

## IaaS, PaaS, SaaS
- IaaS = Virtual Machines
- PaaS = App Service, Azure SQL Database
- SaaS = Microsoft 365

## Storage
- Hot = Frequent
- Cool = Rare but immediate
- Archive = Long-term

## Networking
- VNet = Private network
- VPN Gateway = Site-to-Site VPN
- ExpressRoute = Private dedicated connection

## Security
- B2B = Partners
- B2C = Customers
- Conditional Access = MFA
- Defender = Security posture
- WAF = Layer 7

## Monitoring
- Azure Monitor = Metrics & Logs
- Log Analytics = Queries
- Service Health = Azure outages

## Governance
- Management Groups = Multiple subscriptions
- Azure Policy = Compliance
- RBAC = Permissions
- Tags = Cost allocation

## Cost
- Pricing Calculator = Future cost
- Cost Management = Current cost
- Reserved Instances = VM savings

## Quick Memory Tricks
- Datacenter failure → Availability Zones
- Region disaster → Region Pairs
- Bulk upload → AzCopy
- Web app slow → Application Insights
- Hadoop → HDInsight
- Private Preview → Invite only
- VMSS → 1,000 VMs
